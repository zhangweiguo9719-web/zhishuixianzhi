# 🏭 基于时空深度学习的泵站设备预测性维护与能效优化系统

## 📋 项目简介

这是一个**工业级**的泵站设备预测性维护与能效优化系统，基于真实的Kaggle Pump Sensor Dataset，使用深度学习技术实现设备健康预测和智能节能调度。

**核心创新点**：
- 🎯 **真实工业数据集**：使用Kaggle Pump Sensor Data (22万+条真实传感器数据)
- 🧠 **深度学习驱动**：PyTorch LSTM神经网络进行时序预测
- 🔬 **科研级预处理**：ST-LLM启发的智能数据插补和降维算法
- 📊 **工业级可视化**：实时监控大屏 + 预测性维护决策支持

## 🏆 参赛优势

✅ **技术先进性**：PyTorch深度学习 vs 传统机器学习
✅ **数据真实性**：工业传感器数据 vs 模拟数据
✅ **系统完整性**：端到端解决方案 vs 单点算法
✅ **演示震撼性**：实时交互界面 vs 静态PPT
✅ **科研规范性**：标准工程结构 + 完整文档

## 🚀 快速开始

### 方法一：一键启动（推荐）

1. **双击运行** `启动系统.bat`
2. 系统会自动：
   - 检查Python环境
   - 安装所有依赖包
   - 下载演示数据集
   - 启动AI监控界面

### 方法二：手动安装

```bash
# 1. 安装PyTorch (深度学习框架)
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu

# 2. 安装其他依赖
pip install -r requirements.txt

# 3. 运行数据预处理
python preprocessing.py

# 4. 训练深度学习模型
python train.py

# 5. 启动可视化界面
streamlit run app.py
```

## 🧠 技术架构

### 数据处理流水线
```
原始数据 → 清洗去噪 → 缺失插补 → 降维采样 → 特征工程 → 归一化 → 序列构造
```

### 深度学习模型
```
输入层 (51维传感器) → LSTM层 (128单元×2层) → 全连接层 → 输出层 (健康评分)
```

### 系统架构图
```
[真实传感器数据] → [ST-LLM预处理] → [LSTM训练] → [推理引擎] → [可视化大屏]

             智能插补算法              双向LSTM        实时预测API
             降维优化策略              早停机制        健康趋势分析
```
